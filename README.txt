GitHub Pages publishing:
1. Open your repository: mayyasjourney.github.io
2. Choose Add file > Upload files.
3. Upload index.html, style.css and script.js (not this ZIP).
4. Commit the changes to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait for deployment and visit https://mayyasjourney.github.io
